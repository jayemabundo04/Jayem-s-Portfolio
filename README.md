# Jay-Em's Portfolio

A professional personal portfolio for Jay-Em, built with Next.js, TypeScript, and Tailwind CSS.

## Current Phase

Phase 1 is focused on the application foundation:

- Next.js App Router setup
- Strict TypeScript configuration
- Tailwind CSS styling
- Base layout, navigation, footer, and home page

Database-backed projects, contact storage, Prisma, authentication, and admin management are intentionally reserved for later phases.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Validate the app:

```bash
npm run lint
npm run typecheck
npm run build
```

## Environment Variables

Copy `.env.example` to `.env` and fill values when the related phase is implemented. Do not commit real secrets.
